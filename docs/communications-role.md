# حساب العلاقات العامة والإعلام

يختار المدير العام نوع «العلاقات العامة والإعلام» عند إنشاء الحساب أو تعديل نوع حساب قائم. يستخدم الحساب البريد الإلكتروني وكلمة المرور للدخول.

الدور `communications_editor` يجمع صلاحيات لجنة الإعلام ولجنة الشراكات: إدارة الأخبار ومسوداتها ونشرها وسحب نشرها، وإضافة الشراكات وتعديلها وحذفها، واستخدام مكتبة الصور ضمن قواعد ملكية الصور وربطها بالمحتوى. الحذف النهائي للأخبار يظل للمدير العام.

لا يمنح الدور إدارة الفريق أو الفعاليات أو طلبات الانضمام أو الرسائل أو إعدادات الموقع أو الحسابات. تُفرض الحدود بسياسات قاعدة البيانات، وتُقرأ الصلاحيات من التعيين الحالي في `club_admins`.

يتطلب النشر تطبيق ترحيل `communications_role` وتحديث دالة `media-accounts` والواجهة. لا تتغير أنواع الحسابات الحالية تلقائيًا.
