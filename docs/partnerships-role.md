# صلاحية لجنة الشراكات

يختار المدير العام «لجنة الشراكات» من قائمة نوع الحساب نفسها في لوحة المحررين، عند إضافة الحساب أو تغيير نوع حساب موجود. تستخدم الحسابات اسم مستخدم وكلمة مرور مثل بقية الحسابات، دون شاشة إنشاء منفصلة.

الدور المخزن هو `partnerships_editor`. تظهر له لوحة لجنة الشراكات وتبويبا «الشراكات» و«صور الشراكات» فقط. يدير بيانات الشراكة العربية والإنجليزية ونوعها وروابطها وصورها، ويعاين الشكل قبل الحفظ، ويحفظ وينشر مباشرة وفق السلوك الحالي لقسم الشراكات، ويحذف سجل الشراكة عند الحاجة.

لا يملك إدارة الأخبار أو الفعاليات أو الفريق أو التسجيلات أو الحسابات أو إعدادات الموقع. لا تُشتق الصلاحية من ظهور الشخص في فريق النادي أو عضويته العامة. يظل المدير العام والمحرر العام محتفظين بصلاحيات الشراكات الحالية.

تُفرض العمليات بسياسات قاعدة البيانات والتخزين، لا بأزرار الواجهة فقط. مكتبة الصور لهذا الدور تعرض مرفوعاته والصور المرتبطة بالشراكات. لا يستطيع إرفاق صورة خاصة بقسم آخر عبر تخمين رابطها. يمكنه حذف ملفاته غير المرتبطة؛ يُمنع حذف أي صورة ما زالت مستخدمة في شراكة أو في أي محتوى آخر، ويُمنع حذف ملفات رفعها مستخدم آخر. يستطيع إزالة الصورة من سجل الشراكة دون حذف الأصل المشترك.

تتحقق خدمة إنشاء الحساب من جلسة المدير وتقبل النوع الجديد ضمن القائمة المسموحة. يستطيع المدير إسناد الدور وتغييره وسحبه، بينما لا يستطيع عضو الشراكات رفع صلاحياته. سحب الدور يوقف صلاحيات الطلب التالي؛ واجهة الجلسة تتحدث عند دورة التحقق الحالية.

هذه الصلاحية لإدارة قسم الشراكات الموجود: تعريف الجهات الشريكة ووصف الشراكة ونوعها وروابطها وصورها. لا تعني إضافة نظام اتفاقيات أو عقود أو مراسلات أو مستندات خاصة جديدًا.

التحقق: اختبارات مباشرة للإضافة والتعديل والحذف والواجهة العامة، ومنع الأقسام الأخرى ومسار التوافق القديم، ورفع الصور وربطها وإعادة تسميتها وحمايتها من الحذف أثناء الاستخدام، وتعيين الدور وسحبه. لا يغيّر التحديث بيانات الشراكات الحالية أو Google Sheets أو صلاحيات اللجان الأخرى.
