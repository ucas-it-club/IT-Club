# لجنة الفعاليات

الدور `events_editor` يُختار من «نوع الحساب» عند إنشاء حساب أو تعديل نوع حساب قائم بواسطة المدير العام.

يمكن للحساب إضافة الفعاليات وتعديلها وحذفها، وضبط تشغيل نموذج التسجيل وحقوله، وإدارة الصور الخاصة بالفعاليات ضمن قواعد الملكية والربط الحالية. لا يملك صلاحيات الأخبار أو الشراكات أو الفريق أو طلبات الانضمام أو الرسائل أو إعدادات الموقع أو إدارة الحسابات.

سكربت Google Sheets لم يتغير بناءً على طلب المستخدم. لذلك إنشاء وربط تبويب تسجيلات الفعالية يظل للمدير العام. حفظ اللجنة للفعالية لا يحاول تنفيذ عمليات الشيت المخصصة للمدير، وتوضح الواجهة ضرورة ربط التبويب قبل استقبال تسجيلات الطلاب. لا يمنح هذا الدور صلاحية مشاركة Google Drive أو قراءة الشيت الكامل.

النشر يتطلب ترحيل `events_committee_role` ودالة `media-accounts` المحدثة والواجهة؛ لا يحتاج نشر Google Apps Script أو تغيير الحسابات الموجودة.
